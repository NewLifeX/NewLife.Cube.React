## 1. 编码方案与拆分决策

- 模块前缀：`SKIN`(皮肤集成·.NET) / `FND`(基础框架) / `AUTH`(认证登录) / `LIST`(通用列表页) / `FORM`(通用表单页) / `CMP`(公共组件) / `HOME`(首页) / `META`(页面呈现架构) / `ITYPE`(ItemType 呈现能力) / `PKG`(公共包) / `CI`(工程发布) / `TST`(测试) / `DOC`(文档)
- 功能编码：`{MOD}-{N}`，子功能 `{MOD}-{N}{a/b/c}`
- **三维状态**：实现 / 测试 / 注释（✅ 完成 | — 不适用）
  - 前端功能"实现"= UI 页面/组件可用；"测试"= 单元测试或 E2E 覆盖；"注释"= 关键公开 API 有 JSDoc/TS 注释
  - 后端功能"测试"= 单测或集成验证；"注释"= public API 有 XML 注释
